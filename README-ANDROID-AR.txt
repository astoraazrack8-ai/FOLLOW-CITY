FOLLOW CITY — Android-ready source (Prototype 0.2)
====================================================

ما الذي جهزته؟
- نقلت Three.js من روابط CDN إلى اعتماديات npm؛ Vite يجمعها داخل التطبيق.
- ملفات المدينة والنماذج GLB وcatalog.json موجودة محلياً داخل public.
- بعد تثبيت APK، اللعبة الأساسية لا تحتاج إنترنت لتشغيل المحرك أو تحميل النماذج.
- حفظ تلقائي محلي للمدينة، مع استعادة المباني والطرق والإحصائيات عند فتح اللعبة.
- جهزت مشروع Capacitor وGitHub Actions لبناء APK سحابياً.

مهم:
هذه حزمة مصدر جاهزة للبناء وليست APK مبنياً بالفعل. بيئة هذه الجلسة لا تحتوي Android SDK/Gradle ولا تستطيع الوصول إلى npm لتنزيل الاعتماديات، لذلك لم أستطع إخراج APK مُختبَر هنا.
اللعب عبر ميزات المجتمع في النموذج محاكاة محلية وليست شبكة اجتماعية حقيقية.
توافق الأداء يعتمد على جهاز أندرويد ودعم WebGL/GPU. لا يمكن ضمان كل الأجهزة.

طريقة استخراج APK من الجوال فقط:
1. أنشئ مستودعاً جديداً على GitHub من المتصفح.
2. ارفع جميع محتويات هذا المجلد إلى المستودع (وليس ملف ZIP نفسه).
3. افتح تبويب Actions في المستودع واسمح بتشغيل GitHub Actions إذا طلب ذلك.
4. شغّل workflow باسم "Build FOLLOW CITY APK" من Run workflow، أو انتظر البناء التلقائي بعد رفع الملفات إلى فرع main.
5. بعد نجاح البناء، افتح نتيجة التشغيل وانزل إلى Artifacts.
6. نزّل FOLLOW-CITY-debug-APK.zip، وافتحه على هاتفك، ثم ثبّت app-debug.apk.

تشغيل نسخة الويب محلياً للتطوير:
- npm install
- npm run dev

بناء Android يدوياً على جهاز تطوير:
- npm install
- npm run build
- npx cap add android
- npx cap sync android
- افتح مجلد android في Android Studio وابنِ APK.

الاعتماديات:
- Three.js 0.160.0
- Capacitor 6.2.1
- Vite 5.4.14
